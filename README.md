# Amin Darouiche — creatief portfolio

Een kleine, snelle portfoliosite voor mijn werk rond fotografie, tekenen en grafisch ontwerp.

## Bekijk de website

[Open het portfolio](https://klark1152.github.io/mijn-website/)

## Inhoud

- een overzichtelijke startpagina;
- informatie over mij en mijn creatieve interesses;
- diensten rond creatie, foto-editing en web;
- een galerij die klaarstaat voor nieuw werk;
- een toegankelijke contactpagina.

## Techniek

De site gebruikt bewust alleen HTML, CSS en JavaScript. Daardoor is hij snel, eenvoudig te onderhouden en rechtstreeks te publiceren met GitHub Pages.

## Lokaal bekijken

Clone de repository en open `index.html` in je browser. Voor een lokale server kun je bijvoorbeeld gebruiken:

```bash
python -m http.server 8000
```

Open daarna `http://localhost:8000`.
